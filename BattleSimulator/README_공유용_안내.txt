========================================================================
🚂 Siecletrain 쿼터뷰 열차 슈팅 - 전투 시뮬레이터 공유 가이드
========================================================================

본 시뮬레이터는 압축 해제 후 어느 컴퓨터에서나 즉시 실행 가능하도록
상대 경로(Relative Path) 및 자동 라이브러리 설치 환경이 구축되어 있습니다.

------------------------------------------------------------------------
📌 1. 실행 방법 (컴퓨터에 파이썬이 설치되어 있는 경우)
------------------------------------------------------------------------
1) [run_simulator.bat] 파일(또는 더블클릭)을 실행합니다.
2) 자동으로 필수 라이브러리(PyQt6, openpyxl)를 점검 및 설치하고 UI가 실행됩니다.

------------------------------------------------------------------------
📌 2. 엑셀 데이터 파일 위치 안내
------------------------------------------------------------------------
본 시뮬레이터는 아래 3개 엑셀 파일을 참조하여 실시간 작동합니다:
 - [전투]레벨디자인 및 몬스터 데이터.xlsx
 - [전투]포탑 데이터.xlsx
 - [콘텐츠]트레인 및 승무원 데이터.xlsx

상위 폴더(2_데이터작업)를 통째로 압축하셨거나, BattleSimulator 폴더 안에
엑셀 파일들을 함께 넣어두시면 어디서나 자동으로 인식합니다.

------------------------------------------------------------------------
📌 3. 파이썬 설치가 없는 컴퓨터용 (.exe 단일 실행 파일 제작 방법)
------------------------------------------------------------------------
파이썬이 설치되지 않은 타인 컴퓨터로 공유하고 싶으신 경우:
1) 명령 프롬프트(cmd)에서 `pip install pyinstaller` 실행
2) BattleSimulator 폴더에서 아래 명령어로 .exe 제작:
   pyinstaller --noconfirm --onedir --windowed --name "Siecletrain_BattleSimulator" main.py
3) 생성된 `dist/Siecletrain_BattleSimulator` 폴더를 전달하시면 파이썬 설치 없이 더블클릭으로 바로 실행됩니다!
